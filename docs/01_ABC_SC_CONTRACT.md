# Контракт адаптации и SC-модель интерфейса

## Источник идентификаторов

Редактор сохраняет интерфейс в `concept_ui_interface`. Связь `nrel_ui_has_component` определяет принадлежность компонентов; `nrel_ui_contains` задаёт вложенность. Идентификаторы хранятся через `nrel_ui_id`. Свойство — экземпляр класса `concept_ui_<property>`, связанный с компонентом, с содержимым через `nrel_ui_value`.

Поиск цели выполняется внутри интерфейса. При отсутствии или неоднозначности компонент или свойство отклоняются. Адрес SC-узла не считается постоянным после сохранения интерфейса редактором.

## События и решения

`InteractionEvent` несёт `id`, `user_id`, `interface_id`, `session_id`, тип, время и, при необходимости, `element_id`, `error_code`, действие или изменённое свойство. A формирует `PackageAtoB` со снимком модели, событиями и основанием отправки. `session_id` связывает события текущего сеанса. При двух ошибках одинакового типа одного элемента за сеанс B может сформировать команду показа подсказки.

`CommandBtoC` содержит `request_id`, `interface_id`, `user_id`, `session_id`, `base_version_id`, `target_element_id`, `property`, старое и новое значения, правило, причину, исходные события и ограничения. Версия модели пользователя A и версия интерфейса C — разные значения. B получает активную версию интерфейса через поставщик версии, настроенный интегратором.

Результат C включает `applied`, `rejected` или `failed`, активную версию, причину отказа и `recovery_required`. C передаёт A отдельный `AdaptationResult` с ID исхода, версией до и после, длительностью, основанием и пользовательским контекстом. Технический исход не является событием ошибки пользователя.

## Общий пример

* `hints_panel.visible`: `false → true` для показа, обратный переход — по действию пользователя.
* `history_content.visible`: `true → false` для сворачивания содержимого истории, обратный переход — по действию пользователя. Связь `history_panel → history_content` задаётся через `contains`.
* `font_size` — имя свойства каталога; дополнительное правило шрифта по умолчанию отключено.

При изменении свойств интерфейса содержимое редактора кода и состояние учебной работы не входят в снимок версии. Демо отображает локальное состояние и не выполняет код пользователя.

Термины для будущего представления версий и исходов в БЗ определены в `sc/module_c_adaptation.scs`; серверное хранилище версий в sc-памяти и гарантии транзакций должны быть реализованы вместе с механизмом единого писателя.
